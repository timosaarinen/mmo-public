# About MMO

MMO is an experimental RPG project built around a custom engine and a deliberately simple development philosophy.

The project currently uses assets imported locally from a user's installed copy of World of Warcraft for development and experimentation. Blizzard assets are not stored in this public repository.

MMO is not affiliated with, endorsed by, or sponsored by Blizzard Entertainment.

This repository contains public documentation and media. It does not contain the game source code.
