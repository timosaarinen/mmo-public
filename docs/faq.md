## What is MMO?

A persistent multiplayer RPG experiment. One shared world, NPCs that live in it, and D&D 5e SRD rules underneath. See [About](about.html).

## Is there a story?

Not at the start. World first, story later.

## Is there PvP?

Yes, from day one.

## What does it cost?

The initial plan is free to play, supported by voluntary donations. Donations help pay for better servers.

## Is MMO open source?

No source-code licensing decision has been announced.

## Does this repository contain the game source?

No. This is the public documentation and media repository.

## Does MMO distribute World of Warcraft assets?

No Blizzard game assets are intended to be stored or distributed from this repository.

The project currently works with assets imported locally from the user's own World of Warcraft installation.

## Is MMO affiliated with Blizzard Entertainment?

No. MMO is an independent project and is not affiliated with, endorsed by, or sponsored by Blizzard Entertainment.
