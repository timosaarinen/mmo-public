# MMO

**A new RPG built around a custom real-time path-traced engine.**

This site is the public home for development notes, screenshots, videos, technical material, and releases as the project takes shape.

The game source is developed separately from this public documentation repository.

## Current focus

- Real-time CPU path tracing
- Modern World of Warcraft asset import from the user's local installation
- Character rendering and animation
- Exploration and combat systems
- Desktop-first development
