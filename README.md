## Editing the site

The site is served by GitHub Pages from `docs/` on `main`. There is no build step.

- **Front page copy and hero media:** the front matter of `docs/index.md`.
  To add a screenshot, GIF or video, put the file in `docs/assets/media/` and uncomment the matching `hero` line.
- **Sub-pages:** `docs/about.md`, `docs/media.md`, `docs/faq.md` (plain Markdown).
- **Look and feel:** `docs/_layouts/` and `docs/assets/css/site.css`.
